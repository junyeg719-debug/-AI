# 講師が受講生の進捗を見る仕組み（Googleスプレッドシート）

受講生がアプリでチェックすると、講師のスプレッドシートに進捗が自動でたまります。
講師は「講師用ページ」（`teacher.html`）で、受講生ごとの達成率と最終更新日を一覧で見られます。

> パソコンで作業してください（Apps Script の画面はスマホでは使いにくいです）。

## 1. スプレッドシートと Apps Script を用意する

1. 講師用の Google アカウントで、新しいスプレッドシートを作る（名前は「アクションリスト進捗」など）
2. メニュー「拡張機能」→「Apps Script」
3. 最初から入っている `function myFunction() {...}` を消し、[`Code.gs`](Code.gs) の中身を全部貼り付けて保存（💾）
4. 上の関数の選択欄で `setup` を選び「実行」
   - 「承認が必要です」→ 自分のアカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→「許可」
   - スプレッドシートに「受講生」「進捗」シートができ、講師用パスワードが表示されます

## 2. ウェブアプリとして公開する

1. Apps Script の右上「デプロイ」→「新しいデプロイ」
2. 歯車アイコン →「ウェブアプリ」
3. 実行するユーザー：**自分** ／ アクセスできるユーザー：**全員**
4. 「デプロイ」→ 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー
5. そのURLを `action-list/config.json` の `apiUrl` に入れて main に反映する（Claude に URL を送れば対応します）

> コードを書き換えたときは「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」。URLは変わりません。

## 3. 受講生を登録する

**かんたんな方法（おすすめ）**：受講生がアプリの「講師と共有する」→ 名前を入れて「共有リンクを作る」→ できたリンクをLINEで講師に送る。講師がそのリンクを開くと同じアクションリストが見られ、「受講生」シートにも自動で1行追加されます。

**講師がコードを発行する方法**：

1. 「受講生」シートの A列に名前、C列に担当講師（任意）を書く
2. スプレッドシートのメニュー「アクションリスト」→「受講生コードを発行」→ B列にコードが入る
3. コードを受講生に渡す。受講生はアプリの「講師と進捗を共有する」にコードを入れて「登録」

- 受講生が別のスマホで同じコードを入れると、それまでのチェックが戻ります
- D列の「状態」を **停止** にすると、そのコードは使えなくなります

## 4. スプレッドシートから受講生の進捗を開く

「受講生」「進捗」シートの C列「**進捗を見る**」を押すと、その受講生のアクションリストが**閲覧専用**で開きます（講師のスマホの記録には影響しません。画面の「最新にする」で最新の状態に）。

- 以前の版で作ったシートは、新しいコードを入れたあと最初の通信で自動的に C列が差し込まれます。すぐ入れたいときはメニュー「アクションリスト」→「進捗リンクを入れ直す」

## 5. 講師用ページで見る

`https://junyeg719-debug.github.io/-AI/action-list/teacher.html` を開き、講師用パスワード（メニュー「アクションリスト」→「講師用パスワードを表示」）を入れます。

- 並び順：更新が古い順／達成率が低い順・高い順／名前順。担当講師で絞り込み
- 7日以上更新がない人・未登録の人は赤く表示
- カードを押すと、カテゴリごとにどれが完了・未完了かを確認できます
- パスワードが漏れたときは、メニューの「講師用パスワードを作り直す」

## 送られるデータ

受講生コード・名前・3部門の達成率・完了したアクションのID・最終更新日時。
デート前チェックと話題リストの★は送りません。
