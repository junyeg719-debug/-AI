# 恋愛アクションリスト（スマホアプリ版）

スプレッドシートのアクションリストを、ビジュアル・アプリ・デートの3部門でチェックしていくスマホ向けWebアプリ（PWA）です。
ホーム画面に追加するとアプリのように全画面で起動し、圏外でも開けます。

## 公開URL（GitHub Pages）

`https://junyeg719-debug.github.io/-AI/action-list/`

main ブランチに入ると、`.github/workflows/deploy-demo.yml` がマッチングアプリのデモと一緒に自動で公開します（Pages の設定変更は不要）。


## スマホへのインストール

- **iPhone**：Safariで公開URLを開く → 共有ボタン（□↑）→「ホーム画面に追加」
- **Android**：Chromeで開く → 画面上部の「追加する」、または右上メニュー →「ホーム画面に追加」

## チェックの保存について

チェックとお気に入りは、その端末のブラウザに保存されます（アカウント同期はありません）。
機種変更や別の端末に移るときは、画面下の達成度バーを開いて「バックアップをコピー」→ 新しい端末で「バックアップから復元」。

## スプレッドシートの内容を更新したとき

```bash
bash tools/update_from_sheet.sh
```

`data.json` と `index.html` が作り直されます。インストール済みの端末にも確実に届けるには、`sw.js` の `VERSION` を上げてからコミットしてください。

| ファイル | 役割 |
| --- | --- |
| `template.html` | 画面の本体（`__DATA__` にデータが入る） |
| `data.json` | スプレッドシートから作ったアクションのデータ |
| `index.html` | 公開されるページ（`tools/render.py` が生成） |
| `manifest.webmanifest`, `icons/` | ホーム画面のアプリ名とアイコン |
| `sw.js` | オフライン用キャッシュ |
