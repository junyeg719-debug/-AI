## 3. 会話の記録とルール確認

### 1往復目：あいさつ

> 相手：マッチありがとうございます！よろしくお願いします

> **返事案**：マッチありがとうございます！よろしくお願いします！

判定：あいさつだけ ✓／絵文字なし ✓／「。」なし ✓

### 2往復目：共通点

> 相手：たろうさんもカフェ好きなんですね！休日はよく行かれるんですか？

> **返事案**：はい！休日はだいたいカフェに行ってます！みさきさんはパン屋さんも好きなんですね、よく行くお店はありますか？

判定：相手の質問に答えた ✓／共通点（カフェ）✓／質問1つ ✓／本人情報にない事実を作っていない ✓

### 3往復目：休日の過ごし方を深く

> 相手：中崎町のパン屋さんによく行きます！朝早く行かないと売り切れちゃうんです

> **返事案**：朝から並ぶほど人気なんですね！休日は朝から動くタイプですか？

判定：相手の話に反応 ✓／質問1つ ✓

### 4往復目：会いたい理由を作る

> 相手：休みの日は早起きしてパン屋さんからのカフェが定番です！

> **返事案**：その流れすごく良いですね！僕も梅田のカフェによく行くので、おすすめのパン屋さんの話もっと聞きたいです！

判定：会う理由（店の話を直接聞きたい）を作った ✓／質問なしでも自然 ✓

## 5. 分かったこと（マニュアルへの提案）

1. **会話が9往復になった**。マニュアルの表は5往復目の誘いまでなので、6往復目以降（日付→時間→店→確定）も表に入れると受講生が迷いにくい
2. **確定の文章の例がない**。9往復目のような「日付・時間・店をまとめて伝える例文」を追加するとよい
3. **「〜はどうですか？」の扱い**。店の提案は質問の形になる。「誘いは質問にしない」と「日程や店の確認は質問でよい」の違いを、マニュアルにはっきり書いた
4. **当日の連絡方法**が決まっていない。前日の確認メッセージや、遅れたときの連絡をどうするかは、本人が判断する項目として追加を検討するとよい

## 6. 実在の相手で検証する場合
