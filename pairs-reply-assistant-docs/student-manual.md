# Pairs返信お手伝いツール 設定ガイド（受講生用）

更新日：2026年11月7日

---

## このガイドの使い方

- 上から順番に進めてください。順番を飛ばさないでください
- 1つの手順が終わったら、「次へ進んでよい状態」をすべて満たしているか確認します
- 分からない言葉が出たら、先へ進まずに講師へ質問してください
- 灰色の枠の中の文字は、そのままコピーして使います

---

## 最初に知っておくこと

### このツールでできること

| できること | 説明 |
|---|---|
| 返事が必要な相手を探す | 相手が最後に話している会話だけを選びます |
| 返事を考える | 過去の会話と、あなたが入力した情報をもとに考えます |
| 話し方をそろえる | このガイドの「返事のルール」に合わせます |
| 二重送信を防ぐ | 送った相手を記録し、同じ相手へ2回送りません |
| 決まった時間に動く | 朝7時と夜7時に自動で返事の確認を始めます |

### まだできないこと

次のことは、今のツールではできません。「できる」と思って使わないでください。

- 無料いいねを毎日押す
- 新しくマッチした全員へ自動であいさつする
- Googleカレンダーから空いている日を自動で読む
- Googleカレンダーへ自動でデートの予定を入れる
- Withなど、Pairs以外のアプリを動かす
- Macの電源が切れているときに動く

Googleカレンダーは、手順6のようにCodexへ毎回お願いして読んでもらいます。

### 絶対に守る約束

1. **少しずつ試す**：最初は「送らないテスト」を3人分、次に「本当に送るテスト」を1人だけ行います
2. **自分が最後に話している相手には送らない**：相手の返事を待ちます
3. **パスワードや確認番号をCodexへ教えない**：ログインは必ず本人が行います
4. **ロボット確認は本人が行う**：「私はロボットではありません」などの画面が出たら、自動処理を止めます
5. **お金を使う操作をしない**：有料いいね、ポイント購入、有料プランの画面が出たら何も押さずに止めます
6. **Pairs以外の連絡先を自動で交換しない**：LINEなどの交換は本人が判断します

### 利用前の注意

マッチングアプリの多くは、利用規約で自動ツールの使用を制限しています。使う前に、Pairsの最新の利用規約を講師と一緒に確認してください。規約に反すると、アカウントが停止されることがあります。

## よく出てくる言葉

| 言葉 | 意味 |
|---|---|
| Codex | 作業を手伝うAIのアプリ |
| スキル（手順書） | Codexへ渡す「作業のやり方」のファイル |
| ZIPファイル | いくつかのファイルを1つにまとめた箱のようなもの |
| ターミナル | Macへ文字で命令を出すためのアプリ |

| Pairs専用Chrome | 自動処理だけで使う、普段とは別のChrome |
| 往復 | 自分が1回送り、相手が1回返す。これで1往復です |
| アポ可 | デートに使ってよい時間として、自分でカレンダーに書く印 |

## 全体の流れ（7つの手順）

| 手順 | すること | かかる時間の目安 |
|---|---|---|
| 1 | 必要なものを確認する | 5分 |
| 2 | PairsとGoogleカレンダーを開く | 5分 |
| 3 | Codexへ手順書を入れる | 15分 |
| 4 | 自分の情報を入力する | 20分 |
| 5 | 3人分の返事を、送らずに試す | 15分 |
| 6 | Googleカレンダーの読み方を試す | 10分 |
| 7 | 1人だけ本当に送る | 10分 |

設定画面では、左側の1番から7番を順番に押して進めます。

### 用意するもの

- Macのパソコン
- Codex（アプリ）
- Google Chrome
- 本人のPairsアカウント
- 本人のGoogleカレンダー
- インターネット
- 配布されたZIPファイル（`pairs-reply-assistant-student-kit.zip`）

### すること

![画面1：必要なものを確認する画面](slides-assets/step-1.png)

### 次へ進んでよい状態

- [ ] Codexを開けた
- [ ] Pairsへ本人がログインできた

- [ ] インターネットにつながっている

### うまくいかないとき

Pairsの確認画面や「私はロボットではありません」が出たら、本人が画面の指示に従って進めます。Codexに代わりに通過させないでください。

## 手順2　PairsとGoogleカレンダーを開く

### すること

1. Codexの中でブラウザを開きます
2. 1つ目のタブで、Pairsのメッセージ画面を開きます

```text
https://pairs.lv/message/index
```

3. 2つ目のタブで、Googleカレンダーを開きます

```text
https://calendar.google.com/
```

4. 下の文章をコピーして、Codexへ送ります

```text
現在開いているPairsのメッセージ画面とGoogleカレンダーを確認できますか？
まだメッセージ送信や予定登録は行わず、見えているかだけ教えてください
```

![画面2：PairsとGoogleカレンダーを確認する画面](slides-assets/step-2.png)

### 次へ進んでよい状態

Codexから「両方見えています」という意味の返事が来た状態です。

- [ ] Pairsのメッセージ画面が見えている
- [ ] Googleカレンダーが見えている

### うまくいかないとき

| 起きたこと | すること |
|---|---|
| ログイン画面が出た | 本人がログインする |
| 画面が真っ白 | ページを読み直す（`command` と `R` を同時に押す） |
| Codexから「見えない」と言われた | タブを閉じずに、もう一度同じ文章を送る |

## 手順3　Codexへ手順書を入れる

ここでは、Codexが返事を考えるときに使う「手順書（スキル）」をMacへ入れます。少し長いので、A〜Eの順に進めます。

### A. ZIPファイルを開く

1. 配布された `pairs-reply-assistant-student-kit.zip` を探します（多くの場合「ダウンロード」フォルダにあります）
2. ZIPファイルをダブルクリックします
3. `pairs-reply-assistant` というフォルダができたことを確認します

### B. ターミナルを開く

1. キーボードの `command` と `space` を同時に押します
2. `ターミナル` と入力します
3. 表示された「ターミナル」を開きます

### C. フォルダの中へ移動する

1. ターミナルへ `cd` と入力し、その後ろに**半角の空白を1つ**入れます
2. Aでできた `pairs-reply-assistant` フォルダを、ターミナルの画面へドラッグします
3. `return` キーを押します

### D. 手順書を入れる

次をコピーしてターミナルへ貼り付け、`return` キーを押します。

```bash
bash scripts/install.sh
```

![画面3：手順書をCodexへ入れる画面](slides-assets/step-3.png)

次の言葉が表示されたら成功です。

```text
インストールしました
```

続けて、Codexが手順書を読めるか確認します。

1. Codexをいったん閉じます
2. Codexをもう一度開きます
3. 次の文章を送ります

```text
Pairsの返事を手伝うための手順書を確認できますか？
```

`pairs-reply-assistant` があるという返事が来たら成功です。

### E. Pairs専用Chromeへログインする

毎日の自動処理では、普段のChromeとは別の「Pairs専用Chrome」を使います。

1. ターミナルへ次を貼り付けて、`return` キーを押します

```bash
cd "$HOME/.codex/skills/pairs-reply-assistant"
```

2. 続けて、次を貼り付けて `return` キーを押します

```bash
bash scripts/pairs-browser.sh login
```

3. 新しく開いたChromeで、本人がPairsへログインします
4. メッセージ一覧が見えることを確認します
5. そのChromeを閉じます
6. ログインできているか確認するため、次を貼り付けて `return` キーを押します

```bash
bash scripts/pairs-browser.sh check
```

次の表示が出たら成功です（`true` は「はい」という意味です）。

```text
"loggedIn": true
```

普段のChromeを閉じても、専用Chromeのログイン情報は残ります。Pairsから再ログインを求められたときは、本人がもう一度Eを行います。

### 次へ進んでよい状態

- [ ] 「インストールしました」と表示された
- [ ] Codexが `pairs-reply-assistant` を確認できた
- [ ] `"loggedIn": true` と表示された

### うまくいかないとき

| 表示 | 意味 | すること |
|---|---|---|
| `No such file` | 開いているフォルダが違う | Cからやり直す |
| `既に存在します` | 前に入れた設定がある | 何も消さずに講師へ相談する |
| `"loggedIn": false` | ログインできていない | Eの1からやり直す |
| 赤い文字 | 何かの失敗 | 画面の写真を撮り、講師へ送る |

## 手順4　自分の情報を入力する

AIが事実と違う返事を作らないように、あなたの情報を入力します。**ここに書いていないことは、AIは返事に使いません。**

### 入力する内容

| 項目 | 入力例 |
|---|---|
| Pairsで使う呼び名 | たろう |
| 年齢 | 29 |
| 住んでいる地域 | 大阪市 |
| 出身地 | 兵庫県 |
| 仕事 | 営業 |
| 休みの日 | 土日祝 |
| 趣味 | カフェ、筋トレ、旅行 |
| 平日に会える場所 | 梅田 |
| 休日に会える場所 | 梅田、難波 |
| よく使うカフェや店 | 本人が行ったことのある店 |
| 待ち合わせしやすい場所 | 梅田駅の改札前 |
| 最初のあいさつ | マッチありがとうございます！よろしくお願いします！ |

店は、本人が行ったことのある店か、送る前に営業していることを確認できる店だけを書きます。

![画面4：自分の情報を入力する画面](slides-assets/step-4.png)

### 書いてはいけないもの

- パスワード
- 電話番号
- 自宅の詳しい住所
- 会社の正式な名前
- 本人確認書類の画像
- SMSで届く確認番号
- LINEなど、Pairs以外の連絡先

### ファイルを書き出して、正しい場所へ入れる

1. すべて入力したら、画面の「設定ファイルを書き出す」を押します
2. 「ダウンロード」フォルダに `student-profile.md` ができたことを確認します
3. Finderを開き、画面上のメニューの「移動」→「フォルダへ移動」を押します
4. 次の文字を貼り付けて、`return` キーを押します

```text
~/.codex/skills/pairs-reply-assistant/config
```

5. 「ダウンロード」にある `student-profile.md` を、開いた `config` フォルダへドラッグします
6. 「置き換えますか」と聞かれたら、ファイル名が `student-profile.md` であることを確認して「置き換える」を押します

置き換える前に、パスワードや確認番号を書いていないかをもう一度確認してください。

### Codexに確認してもらう

```text
Pairs用の本人情報を確認してください
まだ送信はしないでください
名前、住んでいる地域、休み、趣味、会える場所を短くまとめてください
空欄やおかしい部分があれば教えてください
```

### 次へ進んでよい状態

- [ ] 名前が自分の名前になっている
- [ ] 住んでいる地域が正しい
- [ ] 趣味が正しい
- [ ] 講師の例の情報が残っていない
- [ ] パスワードや確認番号を書いていない

## 手順5　3人分の返事を、送らずに試す

いきなり本当には送りません。まず3人分だけ、返事の「案」を作ってもらいます。

### Codexへ送る言葉

```text
Pairsの返事が必要な相手を下まで確認してください
古いものから3人だけ選んでください
それぞれの過去の会話を読んで返事の案を作ってください
このテストでは絶対に送信しないでください
相手、相手の最後の発言、何往復目か、返事の案、そう考えた理由を見せてください
```

![画面5：3人分の返事を試す画面](slides-assets/step-5.png)

### 3人とも、次を確認する

- [ ] 相手が最後に話している
- [ ] 相手の質問に答えている
- [ ] 前に聞いた質問を、もう一度聞いていない
- [ ] 手順4で入力していない情報を、勝手に作っていない
- [ ] 丁寧な言葉になっている
- [ ] 顔文字や絵文字が入っていない
- [ ] 「。」が入っていない
- [ ] 質問は1つまで
- [ ] 往復の回数に合った内容になっている（下の表）

### 往復ごとの進め方

| 往復 | 話すこと | 例 |
|---|---|---|
| 1往復目 | あいさつだけ | マッチありがとうございます！よろしくお願いします！ |
| 2往復目 | 相手との共通点を1つ見つける | プロフィールにカフェ好きと書いてあって気になりました！ |
| 3往復目 | 休みの日や普段の過ごし方を少し深く聞く | 休みの日はどのあたりのカフェに行くことが多いですか？ |
| 4往復目 | 「直接会って話したい」理由を作る | おすすめのお店の話、すごく気になります！ |
| 5往復目 | 軽くお茶に誘う | その話直接聞いてみたいので今度お茶でもしましょう！ |

5往復目で誘えなかった場合も、6往復目までには誘います。

### 送らずに「本人に確認が必要」とするとき

次のどれかに当てはまる相手には、自動で送りません。Codexに「本人に確認が必要」と報告させ、本人が判断します。

- 自分が最後に送っている
- 相手がはっきり断っている
- 相手が怒っている、または不安そうにしている
- お金やポイントの話が出ている
- 本人確認が必要な内容がある
- 答えが手順4の情報にない
- LINEなど、Pairs以外の連絡先の話が出ている

### 次へ進んでよい状態

- [ ] 3人とも、上のチェックがすべて入った

合格したら、設定画面のチェックを入れます。まだ人数は増やしません。

## 手順6　Googleカレンダーの読み方を試す

**この機能は、自動返信プログラムにはまだ入っていません。** Codexにブラウザでカレンダーを見てもらう方法を練習します。

### A. デートに使ってよい時間を自分で書く

Googleカレンダーで、デートに使ってよい時間に、次の名前の予定を作ります。

```text
アポ可 梅田
```

`アポ可` の後ろには、会える地域を書きます。

「予定が入っていない時間」を勝手に使わせないため、必ず自分で `アポ可` と書いた時間だけを使います。

### B. Codexに読んでもらう

```text
Googleカレンダーを読み直してください
アポ可と書かれた予定を探してください
日付、曜日、時間、場所を見せてください
まだPairsへ送信せず、予定も追加しないでください
```

![画面6：Googleカレンダーを試す画面](slides-assets/step-6.png)

自分で書いた `アポ可` が、日付・時間・場所とも正しく表示されたら成功です。

### C. 日程を決める順番

デートの日程は、次の順番で1つずつ決めます。一度に全部決めようとしません。

1. 相手をお茶やご飯に誘う
2. 相手から「行きたい」という返事をもらう
3. Googleカレンダーを読み直す
4. **日付だけ**を相手に見せる
5. 相手が日付を選ぶ
6. その日の**時間**を見せる
7. **店**を決める
8. 全部決まったら、カレンダーに予定を入れる

日付を見せる例：

```text
ありがとうございます！11/8（日）11/14（土）11/15（日）あたり予定どうですか？
```

相手が日付を選んだ後に、時間を見せる例：

```text
ありがとうございます！その日なら15時からはいかがですか？
```

### D. カレンダーへ予定を入れてよい条件

次の5つが**全部**決まったときだけ、予定を入れます。1つでも決まっていなければ、まだ入れません。

- [ ] 何をするか（お茶、ご飯など）
- [ ] 日付
- [ ] 始まる時間
- [ ] 会う地域
- [ ] 店

## 手順7　1人だけ本当に送る

手順5の「送らないテスト」に合格したら、1人だけ本当に送ります。

### 送る前に確認すること

- [ ] 相手を間違えていない
- [ ] 相手が最後に話している
- [ ] 返事の内容が、手順4の情報と合っている
- [ ] 同じ質問を前にしていない
- [ ] 日付や時間を勝手に決めていない

### 1人だけ動かす

ターミナルで、次を**1行ずつ**貼り付けて `return` キーを押します。

```bash
cd "$HOME/.codex/skills/pairs-reply-assistant"
```

```bash
bash scripts/pairs-browser.sh reply --limit=1
```

送る前の確認が表示されたら、相手の名前と文章を読んでから進めます。

![画面7：本番を始める画面](slides-assets/step-7.png)

### 送った後に確認すること

Pairsを開いて、次を確認します。

- [ ] 正しい相手に送られている
- [ ] 文章が途中で切れていない
- [ ] 同じ文章が2回送られていない
- [ ] 自分の文章が一番下にある

### 人数の増やし方

1人で成功したら、**別の日に**3人で試します。その後も次の順番で、1段階ずつ増やします。

```text
1人 → 3人 → 5人 → 10人 → 最大30人
```

30人は「必ず送る人数」ではなく「これ以上は送らない上限」です。返事が必要な相手が8人なら、8人で終わります。人数を増やすために、返事が来ていない相手へ追加で送ってはいけません。

## 毎日自動で動かす設定

**1人・3人・5人のテストにすべて合格してから**行います。

ターミナルで、次を1行ずつ貼り付けて `return` キーを押します。

```bash
cd "$HOME/.codex/skills/pairs-reply-assistant"
```

```bash
zsh scripts/install-schedule.sh
```

成功すると、朝7時と夜7時に返事の確認が自動で始まります。

### 自動で動くための条件

- Macの電源が入っている
- Macに本人がログインしている
- Macが完全にスリープしていない
- インターネットにつながっている
- Pairs専用Chromeのログインが切れていない

普段のChromeを閉じていても動きます。Macの電源が切れていたり、完全にスリープしていたりすると動きません。

### 自動処理を止めたいとき

Codexへ次のように頼み、止まったことをCodexに確認してもらいます。

```text
Pairsの朝7時と夜7時の自動処理を止めてください
止まったかどうかも確認して教えてください
```

---

## 毎日の動き

| 時間 | 動くこと |
|---|---|
| 朝7時 | 返事が必要な相手を探し、返事を作って送る |
| 夜7時 | もう一度、返事が必要な相手を探して送る |

無料いいねは、今のプログラムにはまだ入っていません。

### 終わった後の報告の読み方

```text
見つけた人数：12人
送れた人数：8人
送らなかった人数：2人
本人確認が必要：1人
失敗：1人
```

| 項目 | 意味 | すること |
|---|---|---|
| 見つけた人数 | 返事が必要だった相手の数 | なし |
| 送れた人数 | 実際に送った数 | なし |
| 送らなかった人数 | ルールにより送らなかった数 | なし |
| 本人確認が必要 | 本人の判断が必要な相手 | Pairsを開いて本人が返す |
| 失敗 | 途中で止まった | 相手と理由を確認し、送れたかPairsで見る |

---

## 返事のルール

### 必ず守ること

- 相手の話を読んでから返す
- 相手の質問に答える
- 丁寧な言葉を使う
- 相手と同じくらいの長さにする
- 質問は1つまで
- 顔文字や絵文字を使わない
- 「。」を使わない（「！」や改行で区切る）
- お茶に誘うときは「〜しましょう！」の形にする。「〜しませんか？」のような質問の形にしない
- 日付や時間を相手に選んでもらうときは、質問の形でよい

### 良い例

```text
僕も休日はカフェに行くことが多いです！最近行って良かったお店はありますか？
```

相手の話に答えてから、質問を1つだけしています。

### 良くない例

```text
そうなんですね。休みは何曜日ですか？仕事は何ですか？どこに住んでいますか？
```

「。」を使っていて、質問が3つあります。相手の話にも答えていません。

## 困ったとき

| 起きたこと | すること |
|---|---|
| Pairsのログイン画面が出た | 本人がログインする。パスワードはCodexへ送らない |
| 「私はロボットではありません」が出た | 自動処理を止め、本人が画面を確認する |
| 相手が怒っている | 自動で返さない。本人または講師が確認する |
| 自分が最後に話している | 送らない。相手の返事を待つ |
| 日程が分からない | 勝手に決めない。カレンダーの `アポ可` を確認する |
| 送れたか分からない | もう一度送らない。Pairsを開いて確認する |
| 有料の画面が出た | 何も押さずに止める |
| 画面が途中で止まった | 下の4つを順番に行う |

画面が途中で止まったとき：

1. ページを読み直す
2. もう一度、一番下まで見る
3. 2回失敗したら止める
4. どの画面で止まったかを講師へ報告する

## 最後の確認

すべてにチェックできたら、本番へ進めます。

- [ ] PairsとGoogleカレンダーへ本人がログインできた
- [ ] Codexへ手順書を入れた
- [ ] 自分の情報を入力した
- [ ] パスワードや確認番号を書いていない
- [ ] 3人分の送らないテストに合格した
- [ ] 1人だけの送信テストに合格した
- [ ] 同じ文章が2回送られていない
- [ ] 自分が最後に話している相手へ送っていない
- [ ] 有料の操作をしていない
- [ ] 自動処理を止める方法が分かる
- [ ] Macの電源が切れていると動かないことを理解した
- [ ] 30人は「上限」であり、必ず送る人数ではないことを理解した

速さより、間違えないことを優先してください。少しずつ人数を増やしましょう。
